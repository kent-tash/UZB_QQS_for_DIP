# Скан чеков Узбекистана — Версия 1.15.0

## Для RuStore (Краткое описание изменений)

• **Новое имя и логотип:** Приложение переименовано в «Скан чеков Узбекистана», обновлена официальная иконка во всех разрешениях.
• **Единая шторка меню:** Навигация между разделами («Пользователи», «Резервная копия», «Справка», «О приложении») теперь происходит внутри одного окна с плавной анимацией и кнопкой возврата назад.
• **Темы оформления:** Добавлен переключатель тем — системная (авто), светлая и тёмная.
• **Контрастная индикация ролей:** Роль «Аудитор» выделена красным бейджем, «Сотрудник» — синим.
• **Экран сканирования:** Удобная полноширинная карточка профиля для смены пользователя в один тап, убран лишний заголовок.
• **Справка и руководство:** Добавлены пошаговые инструкции по виджету быстрого сканирования и автооткрытию ссылок ОФД (`ofd.soliq.uz`, `my.soliq.uz`, `ofd.multicard.uz`). Все пункты оформлены понятными иконками.
• **Раздел «О приложении»:** Добавлен фирменный логотип и прямая ссылка на страницу в RuStore.

---

## Для GitHub Release (Полный список изменений)

### 🎨 Брендинг и внешний вид
- **Официальный ребрендинг:** Приложение получило актуальное наименование **«Скан чеков Узбекистана»** и обновленный векторный/растровый комплект иконок адаптивного запуска (`mipmap`) и логотипа.
- **Поддержка тем оформления (`ThemeManager`):** Полноценное управление цветовой схемой — системная (автоматически по настройкам устройства), светлая или тёмная тема с мгновенным переключением и сохранением в настройках (`DataStore`).

### 🧭 Навигация и UX-архитектура
- **Единая иерархическая шторка меню (`HierarchicalMenuBottomSheet`):**
  - Подэкраны («Пользователи», «Резервная копия», «Справка и руководство», «О приложении») открываются прямо внутри единого окна.
  - Плавная кинематографическая анимация переходов (slide-in / slide-out) с поддержкой возврата на уровень назад.
  - Улучшенная эргономика управления без закрытия и повторного открытия диалогов.
- **Цветовая дифференциация ролей:**
  - Роль **«Аудитор»** выделена заметным красным статусным бейджем.
  - Роль **«Сотрудник»** выделена синим бейджем.
- **Эргономика главного экрана («Добавить»):**
  - Полноширинная карточка активного профиля с быстрым вызовом переключения в один тап.
  - Удалён дублирующий заголовок «Добавить чек», за счет чего освобождено ценное вертикальное пространство для рабочей области камеры и сканирования.

### 📚 Справка и документация
- **Обновленный экран «Справка и руководство»:**
  - Наглядное оформление каждого раздела тематическими иконками.
  - Инструкция по установке и использованию виджета на рабочем столе для мгновенного запуска сканера в 1 тап.
  - Руководство по настройке браузера и системы для автоматического перехвата ссылок ОФД Узбекистана (`ofd.soliq.uz`, `my.soliq.uz`, `ofd.multicard.uz`).

### ℹ️ Раздел «О приложении»
- Размещение фирменного логотипа высокого разрешения.
- Прямая ссылка на страницу приложения в магазине RuStore для удобного обновления и отзывов.

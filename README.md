# QQS Сканер

Android-приложение для сканирования QR-кодов фискальных чеков Узбекистана (Soliq), сохранения чеков локально, построения отчётов и экспорта данных.

**Версия:** 1.13.0 (Релиз: 27.10.2026)  
**Пакет:** `com.example.uzb_qqs_for_dip`

## Что нового в версии 1.13.0
- 📌 **Залипающая панель сортировки и пакетных действий (Sticky Header)**:
  - Панель сортировки и массовых операций в экране «Чеки и отчёт» теперь плавно фиксируется в верхней части экрана при скролле списка.
  - Постоянный удобный доступ к смене направления сортировки (по дате, сумме, НДС) и пакетным действиям без необходимости листать в самое начало списка.
  - Плавная анимация появления тени (4dp), тональной возвышенности (2dp) и разделителя при залипании.
- 👆 **Улучшенная эргономика управления**:
  - Увеличенная сенсорная зона (min 48dp) для чекбокса выбора всех чеков («Все (N) [✓]»).
  - Тактильный виброотклик (Haptic Feedback) при включении и сбросе массового выбора.
  - Семантическая разметка доступности (Accessibility `paneTitle`) для программ экранного доступа.

## Что нового в версии 1.11.0
- 📊 **Объединённый экран «Чеки и отчёт» (7-блочная архитектура)**:
  - Вкладки «Чеки» и «Отчёты» объединены в единый целостный экран с продуманным интерфейсом.
  - Модульная 7-блочная структура: заголовок периода, сводная статистика (Сумма, НДС, количество чеков), фильтры/поиск, список чеков с управлением, селектор режима экспорта, панель действий и блок архивации/бэкапа.
  - Навигация приложения оптимизирована до 3 основных вкладок: «Сканер», «Чеки и отчёт», «Профиль» (или «Аудит»).
- 📑 **Комбинированный PDF-экспорт (`CombinedPdfGenerator`)**:
  - Новый режим экспорта **«Все» (ALL)** формирует единый непрерывный документ: сводный реестр отчёта + детальные чеки-приложения.
  - Изолированная нумерация страниц для таблицы реестра (`Стр. X из Y`) и автоматическая сквозная компоновка.
  - Поддержка гибких режимов выгрузки: **«Все»** (сводка + чеки), **«Отчёт»** (только реестр) и **«Чеки»** (только чеки).
- 📐 **Компактная вёрстка реестра A4 (24 чека на страницу)**:
  - Оптимизированы поля документа до 28f (~10 мм) и высота строк таблицы.
  - Первая страница реестра вмещает 24 чека с шапкой и итоговым блоком, последующие страницы — до 28 чеков.
- 📖 **Обновлённая справка и тесты**:
  - Добавлено пошаговое руководство по новому экрану в `HelpBottomSheet`.
  - Реализован полный набор тестов для комбинированного PDF-экспортера, проверки границ и пагинации.

## Что нового в версии 1.10.1
- 📷 **Распознавание QR-кодов из галереи через Google ML Kit**:
  - Высокоточное локальное сканирование чеков с фото и скриншотов с использованием Google ML Kit Barcode Scanning.
  - Гибридный декодер: автоматический fallback на ZXing с многопроходной нормализацией (бисекция, инверсия, масштабирование) для сложных и нестандартных изображений.
  - Значительно повышен процент успешного распознавания сжатых, повернутых или снятых под углом чеков из галереи.
- ⚠️ **Интерактивное предупреждение о чеках без НДС (0% НДС)**:
  - При сканировании чека с нулевым НДС отображается диалог с подробной информацией (сумма, продавец).
  - Пользователь может осознанно подтвердить сохранение чека или отклонить его, чтобы исключить попадание чеков без налога в декларации.
- 🔍 **Оптимизация сверки чеков аудитором**:
  - Обновленная логика верификации и визуального отображения статусов чеков при пакетной сверке.

## Возможности

- **Аккаунт** — регистрация профиля сотрудника или аудитора, вход, раздел «Профиль».
- **Сканер** — сканирование QR чека, разбор страницы Soliq, сохранение в локальную базу. Unlimited fast QR scanning with real-time validation.
- **Чеки и отчёт** — объединенный экран: просмотр и фильтрация чеков, сводная статистика за период, выбор режима экспорта (Все / Отчёт / Чеки) в **CSV**, **XLSX**, **PDF** (включая единый PDF со сводным реестром на 24 чека/стр. и приложениями).
- **Аудит** — режим аудитора: проверка сотрудников, сверка деклараций, отчёты по организации. ZIP export for auditor mode.
- **Резервное копирование** — экспорт и импорт данных приложения (JSON), совместимость со старыми версиями бэкапа.

## Системные требования

- **Android** 7.0 и выше (minSdk 24).
- Доступ в **Интернет** (для загрузки и разбора данных чека с Soliq).
- Разрешения запрашиваются в ходе работы приложения (сканер, файлы — по сценарию ОС).

## Сборка из исходников

Требуется **JDK 17** и **Android SDK** (путь к SDK задаётся в `local.properties`, этот файл не хранится в репозитории).

```bash
./gradlew assembleRelease
```

Готовый APK: `app/build/outputs/apk/release/app-release.apk`.

Для подписи release используется локальный keystore (`release.keystore`); файл ключа **не входит** в репозиторий.

## Структура репозитория

- `app/` — модуль приложения (Kotlin, Jetpack Compose).
- `release/` — готовая к установке подписанная сборка.
- Gradle Kotlin DSL: `build.gradle.kts`, `settings.gradle.kts`, `gradle/libs.versions.toml`.

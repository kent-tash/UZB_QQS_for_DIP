# QQS Сканер

Android-приложение для сканирования QR-кодов фискальных чеков Узбекистана (Soliq), сохранения чеков локально, построения отчётов и экспорта данных.

**Версия:** 1.5.0 (versionCode 10)  
**Пакет:** `com.example.uzb_qqs_for_dip`

1. Скачайте файл `.apk` по ссылке выше.  
2. На устройстве откройте **Настройки → Безопасность** (или меню установщика) и при необходимости разрешите установку из источников, отличных от магазина приложений.  
3. Откройте загруженный файл и следуйте подсказкам установщика.

## Возможности

- **Аккаунт** — регистрация профиля сотрудника или аудитора, вход, раздел «Профиль».
- **Добавить** — сканирование QR чека, разбор страницы Soliq, сохранение в локальную базу.
- **Чеки** — список чеков, фильтрация, тип оплаты (наличные / карта / смешанная).
- **Отчёт** — отчёт за период, экспорт в **CSV**, **XLSX**, **PDF** (в том числе сводные таблицы).
- **Аудит** — режим аудитора: проверка сотрудников, сверка деклараций, отчёты по организации.
- **Резервное копирование** — экспорт и импорт данных приложения (JSON), совместимость со старыми версиями бэкапа.

## Системные требования

- **Android** 7.0 и выше (minSdk 24).
- Доступ в **Интернет** (для загрузки и разбора данных чека с Soliq).
- Разрешения запрашиваются в ходе работы приложения (сканер, файлы — по сценарию ОС).

## Сборка из исходников

Требуется **JDK 17** и **Android SDK** (путь к SDK задаётся в `local.properties`, этот файл не хранится в репозитории).

```bash
./gradlew assembleRelease
```

Готовый APK: `app/build/outputs/apk/release/app-release.apk`.

Для подписи release используется локальный keystore (`release.keystore`); файл ключа **не входит** в репозиторий.

## Структура репозитория

- `app/` — модуль приложения (Kotlin, Jetpack Compose).
- `release/` — готовая к установке подписанная сборка.
- Gradle Kotlin DSL: `build.gradle.kts`, `settings.gradle.kts`, `gradle/libs.versions.toml`.

# QQS Сканер

Android-приложение для сканирования QR-кодов фискальных чеков Узбекистана (Soliq), сохранения чеков локально, построения отчётов и экспорта данных.

**Версия:** 1.10.1 (Релиз: 26.10.2026)  
**Пакет:** `com.example.uzb_qqs_for_dip`

## Что нового в версии 1.10.1
- 📷 **Распознавание QR-кодов из галереи через Google ML Kit**:
  - Высокоточное локальное сканирование чеков с фото и скриншотов с использованием Google ML Kit Barcode Scanning.
  - Гибридный декодер: автоматический fallback на ZXing с многопроходной нормализацией (бисекция, инверсия, масштабирование) для сложных и нестандартных изображений.
  - Значительно повышен процент успешного распознавания сжатых, повернутых или снятых под углом чеков из галереи.
- ⚠️ **Интерактивное предупреждение о чеках без НДС (0% НДС)**:
  - При сканировании чека с нулевым НДС отображается диалог с подробной информацией (сумма, продавец).
  - Пользователь может осознанно подтвердить сохранение чека или отклонить его, чтобы исключить попадание чеков без налога в декларации.
- 🔍 **Оптимизация сверки чеков аудитором**:
  - Обновленная логика верификации и визуального отображения статусов чеков при пакетной сверке.

## Что нового в версии 1.10.0
- 📱 **Виджет рабочего стола**:
  - Быстрый запуск сканирования чека по QR-коду прямо с домашнего экрана устройства в один клик.
- 🔗 **Глубокие ссылки (Deep Links) и перехват из браузера**:
  - Автоматическое открытие ссылок на чеки `ofd.soliq.uz` (`/check`, `/epi`), `my.soliq.uz` и `ofd.multicard.uz` из любых приложений (мессенджеры, почта, SMS).
  - Поддержка меню «Поделиться» (Share Target) — мгновенная передача открытого чека из Chrome или другого браузера в приложение.
- 🎛️ **Редизайн панели действий экспорта**:
  - Кнопки «Сохранить», «Поделиться», «Открыть», «Печать» во вкладках «Чеки» и «Отчёты» объединены в компактный горизонтальный ряд с иконками и текстом с автоподгонкой размера шрифта под разрешение экрана.
  - Обновлены цвета кнопок «Открыть» и «Поделиться данными» в блоке резервного копирования на фирменный оттенок `secondaryContainer`.
- 🧾 **Умная обработка чеков без НДС (0% НДС)**:
  - Автоматическое определение чеков без НДС при сканировании и импорте.
  - Исключение чеков с 0% НДС из расчёта возмещения налога в PDF, Excel и CSV-отчётах.
  - Компактный блок статистики и бейджи для аудитора.

## Возможности

- **Аккаунт** — регистрация профиля сотрудника или аудитора, вход, раздел «Профиль».
- **Сканер** — сканирование QR чека, разбор страницы Soliq, сохранение в локальную базу. Unlimited fast QR scanning with real-time validation.
- **Чеки** — список чеков, фильтрация, тип оплаты (наличные / карта / смешанная).
- **Отчёт** — отчёт за период, экспорт в **CSV**, **XLSX**, **PDF** (в том числе сводные таблицы). Strict 2mm bottom margins in reports.
- **Аудит** — режим аудитора: проверка сотрудников, сверка деклараций, отчёты по организации. ZIP export for auditor mode.
- **Резервное копирование** — экспорт и импорт данных приложения (JSON), совместимость со старыми версиями бэкапа.

## Системные требования

- **Android** 7.0 и выше (minSdk 24).
- Доступ в **Интернет** (для загрузки и разбора данных чека с Soliq).
- Разрешения запрашиваются в ходе работы приложения (сканер, файлы — по сценарию ОС).

## Сборка из исходников

Требуется **JDK 17** и **Android SDK** (путь к SDK задаётся в `local.properties`, этот файл не хранится в репозитории).

```bash
./gradlew assembleRelease
```

Готовый APK: `app/build/outputs/apk/release/app-release.apk`.

Для подписи release используется локальный keystore (`release.keystore`); файл ключа **не входит** в репозиторий.

## Структура репозитория

- `app/` — модуль приложения (Kotlin, Jetpack Compose).
- `release/` — готовая к установке подписанная сборка.
- Gradle Kotlin DSL: `build.gradle.kts`, `settings.gradle.kts`, `gradle/libs.versions.toml`.

# Changelog

## [1.6.1] - 2026-10-08

### Что нового (Release Notes)
- Оптимизация кода и удаление неиспользуемых ресурсов для уменьшения размера приложения.

## [1.6.0] - 2026-10-08

### Что нового (Release Notes)
Огромный UI/UX пакет и новые функции для удобства работы:
- **Унификация кнопок 2x2**: обновленный, более понятный дизайн главных экранов.
- **Новые контрастные цвета**: обновленная визуальная тема приложения по стандартам Material Design для лучшей читаемости.
- **Умные И.О. (Авто-ИО)**: интеллектуальное автоматическое заполнение инициалов.
- **Улучшенное меню Аудитора**: добавлено удобное нижнее всплывающее окно (bottom sheet) и новая функция "Сформировать отчет в Аудите".
- **Читаемые ошибки сканирования**: теперь ошибки и предупреждения сканирования отображаются в понятном и удобном для пользователя виде.
- **2-фазный прогресс-бар**: новый индикатор прогресса при сохранении документов, подробно показывающий этапы обработки.
